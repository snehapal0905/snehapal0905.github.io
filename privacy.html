Shorts Agent – Privacy Policy

Last updated: 18 November 2026

Shorts Agent is a personal automation tool that runs on its owner's own computer. It is not a public service and is used only by the owner of the YouTube channel it uploads to.

What data it uses

With the owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos to the owner's channel and to read the channel's name. It requests only these scopes: youtube.upload and youtube.readonly.

How data is stored

The Google sign-in token is stored only on the owner's own computer. No data is sent to any server run by the developer, and no data is sold, shared or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool's use of YouTube is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, and the local token can be deleted by removing youtube_token.json.
